# Third-party notices for the dashboard bundle

`ui/dist` is embedded in every app-tail binary, so what the bundle ships is distributed
with the binary. This lists the runtime dependencies and typefaces in it; the build-time
toolchain (Vite, TypeScript, ESLint, Vitest, Testing Library) ships nothing. The Go
modules in the binary are covered by `internal/licenses/THIRD_PARTY_LICENSES.txt`, printed
by `app-tail licenses`.

| Component | Version | Licence | Source |
|---|---|---|---|
| React, React DOM, scheduler | 19.2.8 / 0.27.0 | MIT | https://github.com/facebook/react |
| lucide-react | 1.45.0 | ISC (icons derived from Feather: MIT) | https://github.com/lucide-icons/lucide |
| qrcode.react | 4.2.0 | ISC (bundles Project Nayuki's QR Code generator: MIT) | https://github.com/zpao/qrcode.react |
| Inter | 4.1 | SIL Open Font License 1.1 | https://github.com/rsms/inter |
| JetBrains Mono | 2.304 | SIL Open Font License 1.1 | https://github.com/JetBrains/JetBrainsMono |

The font files and their licence texts are in `src/assets/fonts/`. This whole file is
appended to `internal/licenses/THIRD_PARTY_LICENSES.txt` by `scripts/licenses.sh`, so
every licence text is carried here in full: the binary is the only copy most people get.
